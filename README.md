# Неписаный реестр

Локальный русскоязычный билдер кампании Malifaux Fourth Edition по разделу
Campaign Mode книги **M4E — Index of the Untold**.

## Запуск

Откройте `index.html` в современном браузере. Сборка и установка пакетов не нужны.

Для локального HTTP-сервера:

```powershell
python -m http.server 4173
```

После запуска откройте `http://localhost:4173`.

## Что уже реализовано

- титульное досье кампании и недельный цикл;
- пять архетипов лидера с корректными характеристиками и ограничениями;
- выбор стартовой Crew Card;
- стартовый арсенал на 25 SS и расчёт стартового скрипа;
- недельный найм с автоматической скидкой 5 скрип на первую модель и налогом за
  non-versatile модель вне ключа;
- травмы моделей, снаряжение и калькулятор Campaign Rating;
- журнал игр с расчётом Aftermath hand, Payday и XP;
- полный 39-ячеечный трек Leadership Experience;
- краткие справочники по травмам, снаряжению и продвижениям;
- автосохранение в браузере, импорт/экспорт JSON и печать.

## Границы первой версии

Эта версия построена только на **Index of the Untold**, как было запрошено. Поэтому
действия и способности моделей пока записываются вручную. Подключение базы Stat Cards
и Upgrade Cards — следующий естественный этап: оно позволит фильтровать допустимые
таланты лидера по фракции, ключу и стоимости автоматически.

Сокращённые русские формулировки в справочнике предназначены для удобства. В спорных
случаях приоритет имеет оригинальная книга.
